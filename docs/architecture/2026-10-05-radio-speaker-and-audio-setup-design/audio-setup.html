What changed from today
  • Five pages become: Outputs, Microphone, Digital modes, TX Profile, Advanced.
  • Each device is set in one place only. The PC mic used to be on two pages.
  • New Radio speaker section, kept in sync with RADIO in the header.
  • Rarely changed device settings fold under "Device details".
  • VAX and TCI share one page. The text no longer says "PipeWire" on a Mac or Windows.
  • Content starts at the top of each page. Today it sinks to the bottom on tall windows.
  • One Rescan button. On Linux it also checks the sound system again.
  • The Linux sound strip no longer sits on every page (on a Mac or Windows it said "Linux audio backend not available"). It is one "Sound system" line on Outputs; Open logs moves to Advanced.
  • Windows-only options are greyed out unless the driver is WASAPI.
  • Every VAX card has a Device row. On Windows it picks the cable, which today can only be done in the first-run dialog.
