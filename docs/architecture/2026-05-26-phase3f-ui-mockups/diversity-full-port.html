§3 The radar widget — what it actually does

Ported from Thetis picRadar_Paint + the inner SensitivityAtAngle(angle, steering) math at DiversityForm.cs:2390-2440. Computes the polar sensitivity pattern of a 2-element phased array using:
  • Current VFO frequency (drives wavelength λ)
  • Antenna spacing in meters (d)
  • Current phase setting
  • Current gain ratio
  • Cross-fire flag
Renders the sensitivity lobe + null direction + cardioid/figure-8/etc pattern shape live as the operator dials. Drag the cursor on the radar to retune phase/gain interactively (Thetis lets you click-and-drag the sensitivity peak — useful for null-on-interference workflow).

Implementation in Qt6: DiversityRadarWidget QWidget subclass with custom paintEvent, ~500 lines including the math (which is ~30 lines, the rest is paint chrome). Source-first port preserves the existing math 1:1.

§4 Thetis-RX1/RX2 concepts → NereusSDR N-slice translation

Some Thetis controls assume a fixed RX1/RX2 pair. Honest translations for our slice model:

radioButtonMerc1/Merc2 → "Reference ADC" radio (ADC 0 / ADC 1). Thetis picks between the two Mercury boards. We pick between the two ADCs directly — same outcome, NereusSDR-native naming.

chkVFOSync → "Sync Slice A → Slice B frequency". Only enabled when Slice B exists. When checked, Slice B's freq follows Slice A's (one-way). Useful for A/B comparison ("listen with diversity on Slice A, listen without on Slice B, switch between to hear the difference"). Greyed out when no Slice B.

chkNoAttLink → "Link ATT between Slice A and Slice B". Renamed for positive semantics (Thetis's double-negative was confusing). Checked = changes to one slice's ATT/preamp propagate to the other.

Andromeda diversity form landscape (Thetis console UI feature) — skip. Andromeda is a Thetis-specific touch-console mode that doesn't apply to NereusSDR's desktop-first UI.

§5 Persistence schema

SliceA_Band_<band>_DiversityEnabled = True/False (14 bands)
SliceA_Band_<band>_DiversityPhase = degrees (14 bands)
SliceA_Band_<band>_DiversityGain = ratio (14 bands)
SliceA_Band_<band>_DiversityFineNull = radians (14 bands)
SliceA_Band_<band>_DiversityCrossFire = True/False (14 bands)
SliceA_Band_<band>_DiversityLockAngle = True/False (14 bands)
SliceA_Band_<band>_DiversityMemoryN_Phase = degrees (14 bands × 8 mems)
SliceA_Band_<band>_DiversityMemoryN_Gain = ratio (14 bands × 8 mems)
Diversity_ReferenceAdc = 0 or 1 (global)
Diversity_AntSpacingMeters = double (global)
Diversity_Calibration = double (global)
Diversity_SyncSliceB = True/False (global)
Diversity_LinkAtt = True/False (global)
Diversity_AlwaysOnTop = True/False (global)
Diversity_AutoAdjust = True/False (global)
Diversity_DialogGeometry = "x,y,w,h" (global)

Per-band keys: 6 controls × 14 bands = 84 + 8 memories × 14 bands × 2 fields = 224 = ~308 persisted values. Global: ~9 keys. Substantial but mechanical.
