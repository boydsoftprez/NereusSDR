Q7 (trimmed): just the layouts operators actually use

5 templates. Each maps to a real workflow. Floating windows for anything beyond.

The 5 layouts we keep

Each template = one specific workflow
ID Shape Workflow it serves
1Single full-size panFocused single-band operation. Default for HL2 + new users.
2vTwo stacked verticallyWide-screen dual-band (e.g. 20m work + 40m monitor). Or DDC pan + wideband-of-same-ADC.
2hTwo side-by-sideTall-screen / portrait dual-band. Or DDC + zoomed-DDC same source.
12hWide top + 2 belowThe wideband workflow: Wideband ADC0 across top (0..61.44 MHz scan), 2 DDC pans below for active work + monitor. Killer layout.
2x24 in a gridContest / multi-band monitor (4 DDC pans, or 2 wideband + 2 DDC).

What we drop and why

✗ 3v (3 stacked vertical) — niche use, 2x2 covers it with a 4th idle pan; 12h serves the "1 wide + 2 below" version better
✗ 4v (4 stacked vertical) — needs an unreasonably tall screen, 2x2 is the better 4-pan layout
✗ 3h2, 2x3, 4h3, 2x4 (5/6/7/8 pans) — beyond realistic max, no operator workflow demands this many tiled panes; floating windows handle the rare "I really want pan #5 on my second monitor" case
✗ 2h1 (2 top + 1 below) — the inverse of 12h, low marginal value, drop for simplicity

Floating window stays

Right-click any pan → "Float pan" → detaches into top-level QWidget for second monitor. Port AetherSDR PanFloatingWindow faithfully. The 2 percent of operators who want 5+ panes visible can float the overflow rather than us shipping 8-pane templates nobody else uses.

Per-pan source picker unchanged

Right-click any pan slot → Source ▶ {DDC pan: A/B/C/D/E, Wideband ADC0, Wideband ADC1}. Capability-gated (HL2 only shows DDC A + wideband ADC0; HermesII shows A/B + wideband ADC0; 2-ADC SKUs show A..E + both wideband ADCs).

Lock: 5 templates (1, 2v, 2h, 12h, 2x2) + per-pan source picker + AetherSDR floating window port. Same as the original 2026-04-09 plan's count, with the wideband source option layered on top and the AetherSDR overlay model handling multi-slice on shared pans.
