WHAT THIS IS

Where reported messages go. Only you and the helpers you name can open it. It lives on the Roundtable web page, behind the same station key the archive uses, so a helper needs no NereusSDR install to work the list.

Nothing is hidden automatically. A message stays visible to everyone (except those who muted its sender) until a person here removes it.

Remove message takes its text off every screen and the archive. The room shows "Message removed" in its place, so the conversation still reads honestly.

Block from posting stops a station sending messages and naming turns, for a set time or for good. It never stops its readings: blocking a station from being heard would change the signal record, and that is never edited.

Leave it closes the report with no change. The reporter is told only that it was looked at.

The helper log shows every action, by whom, so helpers stay accountable to each other.
