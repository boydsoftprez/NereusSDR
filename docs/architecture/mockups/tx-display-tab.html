Notes:

1. Group titles include the Thetis source cite [v2.10.3.13+501e3f51] for traceability. NereusSDR's existing TxDisplayPage at DisplaySetupPages.cpp:2234+ currently has just 4 controls (Background, Grid Color, Line Width, Cal Offset, with the latter two stubbed); Phase 1 expands this page to the full 5-group layout above.

2. P1 = Phase 1 (TX Waterfall Colormap, the immediate "still hot" fix) is the green-bordered group (Waterfall Amplitude Scale). Five controls: Low Level, High Level, Palette, Low Color, and the Custom Gradient picker (which depends on the P2 widget).

3. P2 Custom Gradient Picker is a reusable widget needed for both the TX Waterfall Custom palette AND the TX Panadapter Custom Gradient (Appearance tab). Once it lands it also unlocks the same on the RX side.

4. Cal Offset (P6) is already wired in CalibrationTab.cpp as a UI control but not yet applied to the TX render pipeline. Phase 6 closes that gap.

5. Render-path swap mechanism: Thetis does NOT save/restore on MOX edge. The render path (display.cs:6506-6595 [v2.10.3.13+501e3f51]) does an inline per-frame conditional: if (localMox()) use TX values else use RX values. NereusSDR will mirror this in SpectrumWidget::pushWaterfallRow and the trace render path. No state machine, no event handler.

6. Per-band: none of these settings are per-band in Thetis. All global. Confirmed by exhaustive grep.
