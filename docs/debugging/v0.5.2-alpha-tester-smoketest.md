# NereusSDR v0.5.2 Alpha Test: OpenHPSDR Radios (P1 & P2)

**Hi, and thank you.** This is the v0.5.2 alpha-test guide. v0.5.2 sits on
top of v0.5.1 (patch) and v0.5.0 (substantial minor) and lands one major
epic plus a new SKU port, a new UI subsystem, and a polish tail:

1. **Phase 3P-II: External RF accessories (4O3A PGXL + TGXL) + analog
   S-Meter port.** Power Genius XL amplifier telemetry and Tuner Genius
   XL antenna tuner control over Ethernet, plus the Thetis analog
   S-Meter widget on the operator banner with four RX modes.
2. **ANAN-G2E (HermesC10) SKU port.** New board enum, hardware profile,
   PA telemetry, P2 RX unblock + crash fix.
3. **Applet visibility controller.** Hamburger menu on the AppletPanel
   banner, View → Containers → Applets show/hide, capability-gated
   availability axis, persistent across launches.
4. **Polish tail.** 4O3A integration cleanup (PGXL/TGXL handshake +
   discovery + master toggle gating), TCI live-state fixes and 5 review
   issues, PS-A persistence, PA profile and quit handling, G2E P2 RX
   unblock + crash fix.

Two of the three major items (3P-II and ANAN-G2E) need **specialized
hardware** to fully verify. If you don't have a 4O3A PGXL + TGXL on your
network, or an ANAN-G2E radio, you'll skip those sections; the
applet-visibility menu and the polish tail are testable on any supported
radio.

If you ran the v0.4.0 alpha test, you don't need to redo it. The v0.4.0
doc ([docs/debugging/v0.4.0-alpha-tester-smoketest.md](v0.4.0-alpha-tester-smoketest.md))
is still the right reference for PureSignal, the Display + DSP-Options
refactor, anti-VOX, live-apply sample rate, and the AF Gain + VAX
calibration fix. This v0.5.2 doc focuses only on what changed since
v0.4.0 (covering v0.5.0 + v0.5.1 + v0.5.2 together).

## What's new since v0.4.0 (the short list)

### Shipped in v0.5.0 (2026-05-13)

1. **Phase 3J-1: TCI v2.0 WebSocket server.** External programs
   (WSJT-X, JTDX, FreeDV, Quisk, ESDR3, N1MM, Log4OM, contest software)
   can drive NereusSDR over a Thetis-compatible TCI WebSocket. Setup →
   CAT/Network → TCI Server, Tools → TCI Server log viewer, bottom-bar
   TCI indicator.
2. **Phase 3J-2: Spot system + FreeDV Reporter + PSK Reporter.** Seven
   spot-source clients in one dialog (Tools → Spot Hub, Ctrl+Shift+S):
   DX cluster, RBN, WSJT-X UDP, SpotCollector / DXLab UDP, POTA HTTPS,
   FreeDV Reporter Socket.IO, PSK Reporter IPFIX. Panadapter overlay
   with collision-avoidance stacking + DXCC coloring. Tools → FreeDV
   Reporter (Ctrl+Shift+R) opens the 14-column live station view.
3. **Phase 3R: RADE as a true peer mode (RX + TX end-to-end).** RADE
   is wired as `DSPMode::RADE_U` / `DSPMode::RADE_L`, not a DIGU
   pretense. Mode menu RADE entry, dedicated RadeChannel, RadeApplet,
   VFO flag mode-aware SNR row + speaker callsign. Confirmed on-air on
   ANAN-G2 via remote receivers.

### Shipped in v0.5.1 (2026-05-15)

Patch release. Eight fix-only PRs closing v0.5.0 release-artifact
ship-blockers (Windows installer missing `rade.dll`, macOS x86_64 DMG
built without `Qt6::WebSockets` silently disabling FreeDV Reporter / PSK
Reporter / TCI, HL2 + Windows 11 waterfall sliders not sticking across
launches) and bench correctness fixes (orphan `.bak` data-loss path,
connection state stuck `Connected` on failed initial connect, VOX
needed juggling to prime on connect).

### New in v0.5.2

1. **Phase 3P-II PGXL/TGXL + analog S-Meter port.** Four-phase epic:
   PGXL/TGXL baseline + analog S-Meter port + connection robustness
   (exponential auto-reconnect, keepalive, RTT-correlated ping, full
   PGXL pairing flow, band-change notifications) + advanced UI (PGXL
   Advanced, TGXL Advanced, PGXL Interlock, Fault Log, Tune Memory).
2. **ANAN-G2E (HermesC10) SKU port.** New board enum, hardware profile
   init verified against Thetis v2.10.3.15, codec wrappers, BPF1
   algorithm, PA telemetry, P2 RX unblock + crash fix.
3. **Applet visibility controller.** New `AppletVisibilityController` +
   AppSettings round-trip, hamburger menu embedded in the AppletPanel
   banner, View → Containers → Applets show/hide section,
   capability-gated availability axis, RADE-aware routing, master-toggle
   live UI gating via `RadioModel::fourO3AEnabledChanged`. View →
   Network Applets retired.

## Things to know before you key up

* **Existing settings carry forward.** Saved radios, mic profiles, DSP
  settings, container layout, spectrum/waterfall settings, PA cal
  points, per-band tune power, spot-system identity, FreeDV Reporter
  hidden state, all preserved. No SettingsSchemaVersion bump in v0.5.x
  (last bump was v5 in v0.4.0).
* **3P-II PGXL/TGXL only auto-connects if the master 4O3A toggle is
  on.** If you don't have a PGXL/TGXL on your network, leave the toggle
  off (default). The UI hides AmpApplet / TunerApplet until the toggle
  is enabled.
* **The applet hamburger menu is wired to View → Containers → Applets.**
  Either entry point toggles the same set of applets.
* **No new radio commands ship in v0.5.2.** ANAN-G2E is a new SKU
  recognized via discovery byte 0x14 → HermesC10, but its capability
  row reuses the Hermes-class P1 + P2 command paths.

## Before you start

### Things you need

* A radio (ANAN P1 or P2, HL2, Hermes, Atlas).
* The v0.5.2 build for your platform (Linux AppImage, macOS DMG, or
  Windows installer / portable ZIP) from the GitHub release.
* Optional: 4O3A PGXL + TGXL on the same network (for the 3P-II rows).
* Optional: ANAN-G2E radio (for the ANAN-G2E SKU rows).

### Get the build

* **Linux:** download the AppImage from the release page, `chmod +x`,
  run.
* **macOS:** download the Apple-Silicon DMG, mount, drag NereusSDR.app
  into Applications.
* **Windows:** download either the portable ZIP or the NSIS installer.
  Both ship `rade.dll`, `libfftw3-3.dll`, `libfftw3f-3.dll`,
  `deepfilter.dll`, `dxcompiler.dll`, `dxil.dll`, and Qt runtime DLLs.

### Existing settings carry forward

No schema migration in v0.5.2. The most recent migration was v5 in
v0.4.0 (split DSP-Options Buffer/Filter Size to per-direction). v0.5.0
added per-source spot identity keys, FreeDV Reporter hidden/sort/column
keys, and the per-source `SpotSourceVisible/<source>` panadapter keys.
All default to inactive / off on first launch.

## The actual test

### 1. Applet visibility menu (any radio)

* Connect to your radio.
* Click the hamburger icon at the top of the right-side applet panel
  (banner row).
* Toggle each applet visibility: RX, TX, Phone/CW, EQ, FM, Digital,
  PureSignal, Diversity, CWX, DVK, CAT, Tuner, Amp (Power Genius, shown only when the 4O3A master toggle is on), RADE (shown only
  when the active mode is RADE_U / RADE_L), TCI (shown only when the
  TCI server is enabled).
* Open View → Containers → Applets: same toggle set, two-way sync.
* Close NereusSDR. Reopen. Verify your toggle state persists.

### 2. 4O3A PGXL/TGXL master toggle (PGXL/TGXL hardware required)

* Open Setup → Network → Peripherals.
* The master 4O3A toggle controls whether NereusSDR auto-connects PGXL
  and TGXL on radio-connect.
* With toggle off: AmpApplet and TunerApplet (the Power Genius / Tuner
  Genius rows in the right panel) are hidden; auto-connect does not
  fire.
* With toggle on: both applets appear, PGXL connects to TCP 9008 and
  TGXL to TCP 9010. PeripheralsPage shows live status (Disconnected /
  Connecting / Connected / Connected + paired / Error).
* If you have an actual PGXL and TGXL: verify the PGXL pairing
  handshake (`amplifier create` + `flexradio pair`), the band-change
  push from operator slice → PGXL, the keepalive / ping cadence, and
  the auto-reconnect on transient network drop. Bench-verification
  matrix at `docs/architecture/phase-pgxl-tgxl-smeter-verification/README.md`
  (36 rows total).

### 3. Analog S-Meter widget (any radio)

* Look at the S-Meter on the right-side applet panel. It should be the
  new analog needle (180-degree arc with S-unit scale, not the prior
  composite digital meter).
* Right-click the S-Meter: context menu offers TX Mode (Power / SWR /
  Level / Compression), RX Mode (Signal / Sig Avg / Signal Peak /
  Max Bin), and Peak Hold (Enable + Decay Fast/Medium/Slow + Reset).
* Switch through the 4 RX modes; verify the needle responds.
* Switch Peak Hold to Enable; tune across signals; the peak line should
  decay at the selected rate.
* Close and reopen NereusSDR; verify RX Mode and Peak Hold settings
  persist.

### 4. ANAN-G2E SKU recognition (ANAN-G2E hardware required)

* Power on the ANAN-G2E; verify it appears in the radio chooser with
  the correct "ANAN-G2E" label (not generic HermesC10).
* Connect; verify discovery handshake completes, DDC RX I/Q streams
  flow, audio path works.
* Verify PA telemetry (forward power, supply volts, current) reads
  sensible values on TX.
* Verify Setup → Hardware shows the ANAN-G2E-specific capability gates
  (preamp items, no automatic PA calibration, PA settings bypass
  checkbox, EXT label overrides).
* Bench-verification matrix at
  `docs/architecture/2026-05-21-anan-g2e-verification/README.md` (12
  rows; F2/F3/F4/F6 documented as `DONE_WITH_CONCERNS`).

### 5. TCI server smoke (any radio)

* Setup → CAT/Network → TCI Server: enable server, leave port at
  default (50001), bind interface = loopback (safe default).
* Tools → TCI Server opens the log viewer.
* Connect a TCI client (WSJT-X, ESDR3, N1MM, etc); verify the
  bottom-bar TCI indicator shows Connected (N clients).
* Tune from the client side; verify the operator slice follows.
* MOX from the client side (if your client supports it); verify the
  radio keys.
* For FreeDV / Quisk / JTDX (non-48 kHz audio): verify the per-stream
  resampler kicks in (audio plays clean, no chipmunk effect).

### 6. Spot system smoke (any radio with internet)

* Tools → Spot Hub (Ctrl+Shift+S) opens the 9-tab dialog.
* Settings tab: first-time banner appears (orange-on-dark) if you
  haven't set your callsign. Set callsign + grid square. Banner
  disappears.
* DX Cluster tab: Connect; spots flow in. RBN tab: Connect; spots
  flow in (the RBN host is telnet.reversebeacon.net:7000).
* WSJT-X tab: if WSJT-X is running, decoded callsigns appear in the
  unified Spot List.
* Spot List tab: click a row, verify the active slice tunes to the
  spot frequency.
* Panadapter: spots render with collision-avoidance stacking and
  DXCC-coloring; hover to see the tooltip; right-click to get Tune To
  / Copy Callsign / Lookup on QRZ / Remove Spot.
* Tools → FreeDV Reporter (Ctrl+Shift+R) opens the 14-column live
  station view (if you've set callsign + grid).

### 7. RADE mode smoke (any radio capable of voice TX)

* Mode menu → RADE U (or RADE L). Active mode switches; RadeApplet
  docks in the right column.
* VFO flag: SNR row shows below the mode/filter line (grey when no
  sync, green when synced).
* If a known-good RADE transmitter is on-air on your band: verify RX
  sync acquires within a few seconds, audio decodes, EOO-decoded
  speaker callsign appears prefixed to the SNR row.
* TX (RADE TX): key MOX with RADE active; verify TX RF (use a dummy
  load or attenuator). On-air decode at a remote RX confirms full
  end-to-end; if you have a Web SDR within ground-wave range, this is
  the easiest verification.

### 8. Regression sweep (carry-forward checks)

* **Settings persistence:** close + reopen NereusSDR several times,
  verify VFO frequency, mode, filter, AGC, AF gain, container layout
  all persist.
* **PureSignal (v0.4.0 feature, regression check):** Tools →
  PureSignal opens PsForm. AmpView opens from PsForm's btnPSAmpView.
  Two-tone IMD overlay still draws on the spectrum.
* **Anti-VOX (v0.4.0 feature, regression check):** Setup → Transmit →
  DEXP/VOX still has the grpAntiVOX trio (Enable + Gain + Tau). Slider
  motion still affects the cancellation.
* **AF Gain (v0.4.0 fix, regression check):** AF gain still routes
  through `WDSP.SetRXAPanelGain1` (no +12 dB distortion at default).
  VAX bus stays calibrated as you move AF.
* **Sample rate live-apply (v0.4.0 feature, regression check):**
  Setup → Hardware → sample rate combo still applies without forcing
  disconnect/reconnect. HL2 P1 still offers 384 kHz.
* **Containers + skins (v0.3.x baseline, regression check):**
  drag-to-float, drag-to-dock, container settings dialog all still
  work. Operator skin loads and persists.

## What is NOT wired up (don't file bugs for these)

* **PGXL/TGXL bench-verification matrix is not yet executed on live
  hardware.** The 36-row matrix at
  `docs/architecture/phase-pgxl-tgxl-smeter-verification/README.md`
  is drafted but pending live PGXL + TGXL hardware. If you have the
  hardware and a row fails, that's worth filing.
* **ANAN-G2E bench-verification matrix has 4 documented gaps**
  (F2 / F3 / F4 / F6; see code comments). Bench-verification on live
  G2E hardware is the next gate.
* **HL2 RADE bench verification** is still gated on the HL2
  ATT/filter safety audit closure.
* **RADE multi-slice** (RADE on slice A while SSB on slice B) is
  exploratory; full coverage waits on Phase 3F (multi-panadapter).
* **3M-2 CW TX is not in this release.** Sidetone, firmware keyer,
  QSK/break-in are all not yet wired. CW mode in the mode menu maps
  to the RX-only path. CW TX is the next major epic after v0.5.2.

## Things that might look weird but aren't bugs

* **Power Genius XL applet is named "Power Genius", not "AMP".** The
  rebrand landed in v0.5.2 to match 4O3A's product line.
* **View → Network Applets menu item is gone.** Replaced by View →
  Containers → Applets (same set + more, with the hamburger menu as a
  second entry point).
* **FLEX-discovery broadcasts now go to the computed subnet address,
  not 255.255.255.255.** Required for some LAN topologies where the
  generic broadcast doesn't reach the PGXL. If your PGXL isn't being
  discovered, set its IP statically in Setup → Network → Peripherals.

## Reporting bugs

* If something doesn't work, please file an issue with:
  - Your platform (Linux / macOS / Windows + version).
  - Your radio model.
  - The exact steps you ran.
  - Any relevant log output (Tools → Logs window has a Copy button).
  - Whether the issue reproduces after a clean settings wipe
    (`mv ~/.config/NereusSDR ~/.config/NereusSDR.bak` then relaunch).
* Use the [💡 → Report Bug](#) menu item in the app (top-right corner)
  for an AI-assisted bug report that pre-fills the GitHub issue
  template.
* For PGXL/TGXL or ANAN-G2E issues, please include a packet capture if
  you can (`tcpdump` / Wireshark on your LAN). The protocol surface is
  new and we want raw bytes when something's off.
