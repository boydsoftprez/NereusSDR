# AetherSDR Provenance: NereusSDR ports from AetherSDR

This record lists code NereusSDR ports from AetherSDR, port by port, from the
Display pill work (2026-10-10) onward. Per-file attribution lives in the source
files themselves; this is the grep-able summary.

Ports made before this file existed are recorded in
[`aethersdr-reconciliation.md`](aethersdr-reconciliation.md), which is also the
file `scripts/check-new-ports.py` reads to decide whether a NereusSDR file is
registered as AetherSDR-derived. Both NereusSDR files below are registered
there already. The telemetry graph has its own record in
[`AETHER-TELEMETRY-PROVENANCE.md`](AETHER-TELEMETRY-PROVENANCE.md).

AetherSDR's source files do **not** carry top-of-file copyright or GPL notices.
The project-level GPLv3 licence applies (HOW-TO-PORT.md rule 6): each NereusSDR
file that takes AetherSDR code carries the AetherSDR project-level attribution
block and a "Modification history (NereusSDR)" entry, and each ported block and
constant carries an inline `// From AetherSDR <file>:<line> [@1e0718ad]` cite.
Upstream `//` comments inside ported logic are kept verbatim.
