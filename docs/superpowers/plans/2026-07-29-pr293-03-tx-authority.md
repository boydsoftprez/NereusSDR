# PR 293 Stabilization 03 — Authoritative TX Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ensure every transmit decision follows the stable TX-bound slice, even when the operator listens to or edits a different active slice.

**Architecture:** `RadioModel::txBoundSlice()` is the one lookup for transmit mode, frequency, band, Alex routing, VOX/TGXL state, and WDSP RX suspension. At MOX entry, AudioEngine captures the gated slice ID and RadioModel captures the exact WDSP RX channel stopped; MOX release restores those same identities instead of consulting mutable active state.

**Tech Stack:** C++20, Qt 6, WDSP, AudioEngine/MasterMixer, Alex controller, band-plan guard, CMake/CTest.
