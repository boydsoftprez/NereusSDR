Steinberg ASIO SDK source notices

These copyright and licence notices appear in ASIO SDK source files that
NereusSDR compiles into its programs, and are not carried by asiosdk.txt.
Each notice appears once, exactly as it is written in the first file
listed under it (line endings shown as LF; the SDK's files use CRLF); the
other files listed carry the same notice.

Source: Steinberg ASIO SDK 2.3.4 (ASIO-SDK_2.3.4_2025-10-15.zip). File
paths are relative to third_party/asiosdk/.
Collected by hand from the files the asiosdk_host library compiles
(common/asio.cpp, host/asiodrivers.cpp, host/pc/asiolist.cpp) and the SDK
headers they include; scripts/collect-source-notices.py has no asiosdk
preset. common/asio.cpp, common/asio.h, common/asiosys.h and
common/iasiodrv.h carry no notice of their own: they refer to the SDK's
LICENSE file, which is asiosdk.txt.
