Where it is

The source is in the NereusSDR repository on GitHub, github.com/boydsoftprez/NereusSDR, in the ios folder. That folder holds everything needed to build the app:

  • the app and its Live Activity widget (ios/NereusApp, ios/NereusActivity, ios/Shared);
  • NereusKit, the app's link, media and display modules (ios/NereusKit);
  • the third-party libraries the app includes, at the exact versions it uses, with their licences (ios/THIRD-PARTY.md lists each one, where it came from and its checksum);
  • the project description and build scripts (ios/project.yml, ios/scripts);
  • the licence and its App Store permission (ios/LICENSE).

Which source made your copy

In the app, open Setup, then About this app. The top of the page shows the version and build number.

  • A test build also shows a build line such as claude/iphone-app@cbabbd5bc. The characters after the @ are the start of the commit it was built from. Open https://github.com/boydsoftprez/NereusSDR/commit/ followed by those characters to see that exact source.
  • A build with no build line was made from a commit that carries a tag in the repository. The tags page lists them.

How to get it

On GitHub, open the commit or tag for your build and choose Browse files, then Code, Download ZIP. Or use git: 

git clone https://github.com/boydsoftprez/NereusSDR.git
cd NereusSDR
git checkout <commit or tag>

ios/README.md explains how to build and test the app. Building needs a Mac with Xcode and XcodeGen.

If you cannot download it, ask on the issue tracker and we will send you the source for your version, free of charge.
